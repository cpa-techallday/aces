# UI polish pass 2026-10-16 — instrument-board shape, full click-through

Branch `ui/professional-polish` (worktree `aces-wt-uipolish`, base 282f2f0). Scope: `src/aces-console/static`
plus the browser test suite. No new dependencies, no framework change; the conversational Plan model
(brief → Generate plan → stage cards → spec sheet → Launch with its printed reason) is untouched.

## Design tokens (unchanged set, `static/styles.css:12-52`)

The console keeps its four-ink discipline — chalk for what exists, cyan for what is live, amber for actions
and the thing under the eye, red-orange for the faulted thing only; EB Garamond italic for names, tracked
mono caps for labels, tabular figures; one 2 px radius; no shadows. The harness
(`tests/harness/verify_ui.py`) still rejects any computed colour outside the `:root` token set, and passes.

## What changed (`static/console.css`, four plates)

1. **Blocks are panels.** Every `dom.block()` (plate bodies and the inspector column) renders as a raised
   panel: `--plate-2` surface, hairline `--line-2` border, the cap as a header strip with a rule under it.
   Inset elements inside a panel (cards, stage cards, chips, inline notes) sit one tier down (`--plate`) so
   the panel reads as their frame; the inspector column reverses the tiers (its panels are `--plate` on the
   `--plate-2` column). On a phone the panels meet the screen edges (no side borders).
2. **Tables scroll inside their panel.** `.blk .table-wrap` is capped at 480 px with a sticky header row, so
   the Evidence / Pipeline / Solvers plates are boards of panels instead of multi-thousand-pixel documents.
   The 390 px stacked-rows layout is unchanged (headers hide there, per the existing token sheet).
3. **Row names are quiet controls.** A table row's name that opens a record (solver, experiment, case,
   golden run, CAD run) is a new `.rowbtn`: the serif-italic name itself, underlined on a hairline, amber on
   hover and when its row is under the eye. The amber outline `.btn` is now reserved for controls that act
   (Generate plan, Refresh fabric, Switch mode, Verify, Open, Stop console). This also removes the uppercase
   transform that made row names shout.
