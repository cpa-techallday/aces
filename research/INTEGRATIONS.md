## electronics

Adds pillar 15, Electronics (aces-electronics). KiCad 10 is the native ECAD (Arch extra 10.0.7; the brief's 'KiCad 9' is stale). Fusion Electronics stays read-only: its API has no KiCad import. Agents use kicad-python IPC plus KiCad MCP Pro's read-only profile on day one; writes go through the policy broker. kicad-cli and KiBot run headless as evidence jobs. New fab-release gate before any upload: ERC 0, DRC with project rules, schematic-to-PCB netlist parity (AERIS once passed DRC unwired), vendor-verified footprints, defined stackup, SI run. Uploading Gerbers to JLCPCB or PCBWay is a supply outside Australia (DTC Act s.10), so it needs a DSGL screen and recorded authorisation, approval-gated in every mode. Port SWIG scripts before KiCad 11. OpenROAD and Yosys were checked; not needed now.

## Completeness critic (agent)

Broad and licence-careful on CAD kernels, GPU numerics, evidence, model lanes and media. Thin where customer-zero work lives: UAV/AGV autonomy, machine vision, system, process and aero design, AEC, field telemetry, analytical data. Pick one winner for each of ~14 overlaps before v1 (two policy engines, four gateways, three ROS 2 packagings). Existing and decided parts (gmsh, PyFR, trimesh, ArtCraft ×7, Fusion bridges, planned solvers) and notes-only picks lack rows, so a catalog-derived licence register would be incomplete.

Missing candidates to consider:

- **OpenCV** (field-plc-robot-can (vision)): Camera calibration, hand-eye for the HC10DTP cell, ZED X inspection and fiducial metrology; Apache-2.0; the catalog has no vision base.
